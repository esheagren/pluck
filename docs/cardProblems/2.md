# Atomicity Violation - Compound Definition

## Original Card

**Question:** What is a recurrent neural network (RNN)?

**Answer:** A recurrent neural network is a type of neural network designed to process sequential data by maintaining hidden states that carry information from previous time steps. Unlike feedforward networks, RNNs have connections that loop back on themselves, allowing them to have memory of past inputs.

**Visual:** Small diagram showing RNN architecture with inputs, RNN core, and outputs (decorative)

---

## Problems Identified

### Primary Problem: Not Atomic

This card tries to cover too much in a single question. The answer contains at least two distinct concepts:

1. **What RNNs are designed for** — processing sequential data by maintaining hidden states
2. **How RNNs differ from feedforward networks** — connections that loop back, giving them memory

These are separate ideas that should be tested separately. A learner could understand one without the other.

### Additional Issues

| Problem | Description |
|---------|-------------|
| **Compound answer structure** | The answer has two sentences covering different aspects. When reviewing, the learner doesn't know which part they're being tested on. |
| **Unclear success criteria** | What counts as a correct recall? Just "processes sequential data"? The full mechanism? The comparison to feedforward networks? |
| **Passive definition format** | "What is X?" questions often produce rote memorization without understanding. The learner can recite the definition without being able to apply or reason about it. |
| **Hidden state not explained** | "Hidden states that carry information" is introduced without explanation. What is a hidden state? How does it carry information? |
| **Comparison buried** | The contrast with feedforward networks is valuable but tacked on as secondary information rather than being the focus of its own card. |

---

## Reconstructed Cards

### Card 1: The Core Capability

> **Q:** What problem do RNNs solve that standard feedforward networks cannot?
>
> **A:** Processing data where order matters. A feedforward network sees each input independently with no memory. An RNN maintains a "hidden state" that carries information forward, so each input is processed in context of what came before.

**Why this is better:** Tests understanding of the problem being solved, not just the definition. Frames RNN as a solution to a limitation.

---

### Card 2: The Mechanism (Contrast)

> **Q:** What architectural feature distinguishes RNNs from feedforward neural networks?
>
> **A:** Recurrent connections—outputs loop back as inputs to the same layer. This creates a form of memory: the network's state at time T influences its processing at time T+1. Feedforward networks have no such loops; information flows only forward.

**Why this is better:** Focuses specifically on the structural difference. A learner who knows Card 1 (the problem) can now learn Card 2 (the mechanism) as a separate, atomic concept.

---

### Card 3: The Mental Model (Optional)

> **Q:** If a feedforward network reads a sentence by seeing each word on a fresh blank page, how does an RNN read?
>
> **A:** Like a person reading normally—each word is interpreted in context of everything read so far. The RNN carries forward a compressed summary (hidden state) that colors how it interprets the next input.

**Why this is better:** Creates a sticky analogy that makes the concept intuitive and memorable.

---

## Key Principle

**One concept per card.** When an answer has multiple sentences covering different ideas, that's a signal the card should be split. Each card should have a clear, singular thing being tested.
